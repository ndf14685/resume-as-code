**Responsabilidades y asignaciones**
🔍 Mira cómo será tu día a día:

Diseñar, implementar y mantener Azure Landing Zones siguiendo las mejores prácticas de Microsoft (Cloud Adoption Framework).
Diseñar y gestionar la estrategia de Backup y Disaster Recovery corporativo utilizando Veeam en entornos híbridos y cloud (Veeam Backup for Microsoft Azure).
Automatizar el aprovisionamiento de infraestructura bajo la filosofía Infrastructure as Code (IaC) utilizando Terraform.
Configurar, administrar y asegurar servicios de identidad y acceso mediante Microsoft Entra ID (Federación, RBAC, Conditional Access, etc.).
Administrar y configurar entornos basados en Windows Server (y Linux cuando aplique) dentro de la infraestructura cloud.
Velar por la seguridad, el cumplimiento normativo (governance) y la optimización de costos en las suscripciones de Azure.
Implementar políticas de seguridad, gestión de accesos con Microsoft Entra ID y resguardo de datos (cifrado, inmutabilidad de backups).
Configurar redes virtuales (VNets, VPNs, ExpressRoute, Private Endpoints) para asegurar la conectividad segura de los servicios cloud y locales.
